# 三期 3.1 常见错误说明 v0.1

## 1. 提示“模型未配置”

原因：

- 没有填写 API Key。
- API Key 没保存。
- 模型连接测试未通过。

处理：

1. 进入“初始化配置”。
2. 重新填写 API Key。
3. 点击“保存配置”。
4. 点击“测试连接”。

## 2. 提示“请先完成字段确认”

原因：

- 上传客户库后直接进入运行看板。
- 系统还没有确认哪一列是商品名称、规格、单位等。

处理：

1. 回到“新建对照任务”或字段确认页面。
2. 确认客户库字段和我司库字段。
3. 再进入运行看板。

## 3. 导出按钮不能点

原因：

- 任务还在运行中。
- 任务已暂停或停止。
- 本轮尚未完成。

处理：

- 等待本轮完成。
- 如果任务停止，需要重新开始任务或查看诊断信息。

## 4. 第二轮无法开始

原因：

- 没有先上传人工加工后的 Excel。
- Excel 不是系统导出的格式。
- 人工填写的我司编码不存在于当前我司库。

处理：

1. 使用第一轮导出的 Excel 继续加工。
2. 不要删除 `系统任务行ID`。
3. 如果新增了我司商品，先更新我司商品库。

## 5. 真实模型验证很慢

原因：

- 每条客户商品都可能触发模型比较。
- 网络和模型服务响应速度会影响运行时间。

处理：

- 先用小批量验证。
- 验证通过后再扩大样本。

## 6. 命令行提示找不到 `product_code_mapper`

原因：

- 在后端目录直接执行验证脚本，但没有设置 Python 包路径。

处理：

```powershell
cd phase3_app/backend
$env:PYTHONPATH="src"
```

然后重新运行验证命令。
