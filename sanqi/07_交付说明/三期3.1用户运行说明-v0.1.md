# 三期 3.1 用户运行说明 v0.1

## 1. 启动方式

在项目根目录双击：

```text
启动三期工作台.bat
```

脚本会自动启动 Python 本地服务，并优先打开 Tauri 桌面工作台。

如果桌面程序尚未构建，脚本会回退到浏览器开发模式。

## 2. 首次使用流程

1. 打开首页。
2. 进入“初始化配置”，填写 DeepSeek API Key，并点击“测试连接”。
3. 进入“我司商品库”，上传我司商品库 Excel。
4. 进入“新建对照任务”，上传客户商品库 Excel，或手工输入单条商品。
5. 进入“字段含义确认”，确认系统对 Excel 列名的理解。
6. 进入“运行看板”，系统开始第一轮对照。
7. 第一轮完成后，点击“导出 Excel”。
8. 人工在导出的 Excel 中处理需要审核的行。
9. 如需第二轮，回到运行看板上传人工加工后的 Excel，点击“开始第二轮”。

## 3. 关键规则

- 没有配置模型，不能开始正式对照。
- 没有确认字段，不能开始正式对照。
- 运行中不能导出正式结果。
- 只有本轮完成后，导出按钮才可用。
- 人工确认过的结果，第二轮不会被系统覆盖。

## 4. 输出文件

导出 Excel 至少包含：

- `对照结果总表`
- `详细证据表`
- `候选明细表`
- `统计汇总表`

总表会保留客户原始列，并在后面追加系统对照结果列。
