# 三期 3.1 配置说明 v0.1

## 1. 模型配置

当前 3.1 默认使用 OpenAI 兼容接口，优先支持 DeepSeek。

默认参数：

- Provider：`DeepSeek`
- Base URL：`https://api.deepseek.com`
- Model：`deepseek-chat`

API Key 只在本地使用，不应写入代码、文档、Git 或日志。

## 2. Web 界面配置

在“初始化配置”页面填写 API Key 后，点击：

```text
保存配置
测试连接
```

如果测试连接失败，不要开始对照任务。

## 3. 命令行真实样本验证

如果需要用真实 Excel 做小批量验证，在 PowerShell 当前会话设置环境变量：

```powershell
$env:DEEPSEEK_API_KEY="你的 DeepSeek Key"
```

然后运行：

```powershell
cd phase3_app/backend
$env:PYTHONPATH="src"
python -m product_code_mapper.validation.run_deepseek_sample `
  --company-xlsx "D:\bianmaduizhaoxiangmu\bianmaduizhaoxiangmu_zhuxian\我司商品库.xlsx" `
  --customer-xlsx "D:\bianmaduizhaoxiangmu\bianmaduizhaoxiangmu_zhuxian\客户商品库.xlsx" `
  --output-xlsx "D:\bianmaduizhaoxiangmu\sanqi_publish_clean\runtime_data\validation\deepseek_sample_result.xlsx" `
  --limit 20
```

如果要按共同特征抽样验证，例如只验证客户库里的“生抽”商品：

```powershell
cd phase3_app/backend
$env:PYTHONPATH="src"
python -m product_code_mapper.validation.run_deepseek_sample `
  --company-xlsx "D:\bianmaduizhaoxiangmu\bianmaduizhaoxiangmu_zhuxian\我司商品库.xlsx" `
  --customer-xlsx "D:\bianmaduizhaoxiangmu\bianmaduizhaoxiangmu_zhuxian\客户商品库.xlsx" `
  --output-xlsx "D:\bianmaduizhaoxiangmu\sanqi_publish_clean\runtime_data\validation\deepseek_sample_shengchou_result.xlsx" `
  --limit 5 `
  --customer-keyword "生抽"
```

注意：

- 不要把 Key 写入脚本。
- 先用 10 到 20 行小样本验证。
- 可以用 `--customer-keyword` 按共同特征抽样，避免只验证客户库前几行。
- 验证结果必须人工抽查，不能只看自动统计。
