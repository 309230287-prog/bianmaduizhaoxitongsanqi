# 三期工作台

## 定位

三期从这里重新开始。

本文件夹只承接项目文档、讨论沉淀、需求文档、实施路书和判断准绳，用作三期重新规划的资料基线。

## 硬边界

三期不继承以下内容：

- 一期产品、一期代码、一期 UI、一期字段对照流程
- 当前已经做出的二期代码、二期 UI、启动器、Demo、导出逻辑
- 任何为了临时跑通而写出的产品实现

三期允许继承以下内容：

- 原始讨论文档
- 需求文档
- 实施路书
- 技术规划和判断规则文档
- 项目记忆和任务记录
- 商品库 Excel 作为业务样本，但不作为产品架构来源

## 目录

- `00_文档基线/01_讨论与判断准绳`：项目背景、讨论记录、判断准绳
- `00_文档基线/02_需求文档`：需求文档历史版本
- `00_文档基线/03_实施路书`：实施路书历史版本
- `00_文档基线/04_技术规划与规则`：技术规划、匹配规则、模型配置说明
- `00_文档基线/05_任务书与历史计划`：任务书和历史执行计划
- `00_文档基线/06_项目记忆`：项目记忆
