# 三期工作台

## 定位

三期从这里重新开始。

本文件夹只承接三期允许继承的最小文档基线。

三期从这里重新规划，不沿用一期产品，也不沿用当前二期已经做出的任何交付物。

## 硬边界

三期不继承以下内容：

- 一期产品、一期代码、一期 UI、一期字段对照流程
- 当前已经做出的二期代码、二期 UI、启动器、Demo、导出逻辑
- 任何为了临时跑通而写出的产品实现
- 已写出的实施路书、技术规划、任务书、历史执行计划、项目记忆

三期允许继承以下内容：

- 仅限三份讨论文档：
- `项目背景-当前理解-v1.md`
- `项目讨论记录-二期方向-v1.md`
- `项目判断准绳-二期语义翻译-v1.md`
- 需求文档
- 商品库 Excel 作为业务样本，但不作为产品架构来源

## 目录

- `00_文档基线/01_讨论与判断准绳`：项目背景、讨论记录、判断准绳
- `00_文档基线/02_需求文档`：需求文档历史版本
- `01_文档重梳理`：三期文档重梳理、关键问题默认答案
