# 三期 3.1 低保真原型

这是商品编码对照系统三期 3.1 的本地 HTML 低保真 Demo。

## 用途

用于确认产品画像和主线流程：

- 首页工作台
- 首次启动和初始化配置
- 更新我司商品库
- 新建对照任务
- 对照进度看板
- 导出 Excel
- 人工加工后继续历史任务 / 开始下一轮

## 3.1 范围说明

3.1 不把候选解释、页面明细表、人工审核工作台放进主线。

这些明细第一版先通过导出的 Excel 承接，后续版本再逐步搬回系统界面。

## 打开方式

双击打开：

`index.html`

## 说明

- 这是低保真原型，不是正式产品。
- 不接真实 Excel。
- 不调用模型。
- 不保存任何配置。
- 主要用于确认流程、页面结构和业务人员是否看得懂。
